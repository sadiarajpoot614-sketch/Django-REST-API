# 🚀 Django REST API Project

A professional Django REST API project built using **Django** and **Django REST Framework**.

This project demonstrates API creation, routing, database integration, admin panel support, and a custom homepage using Django templates.

---

## 📌 Features

✅ Django REST Framework API  
✅ Custom Home Page using Django Templates  
✅ API Endpoints  
✅ SQLite Database Integration  
✅ Clean Project Structure  
✅ Django Admin Panel Support  

---

## 🛠️ Technologies Used

- Python 3.11
- Django 5.2.16
- Django REST Framework
- SQLite Database
- HTML & CSS

## ⚙️ Installation & Setup

### 1. Clone Repository

git clone https://github.com/sadiarajpoot614-sketch/Django-REST-API.git


### 2. Create Virtual Environment

python -m venv venv


### 3. Activate Environment

Windows:

venv\Scripts\activate


### 4. Install Dependencies

pip install django djangorestframework


### 5. Run Migrations

python manage.py migrate


### 6. Start Server

python manage.py runserver
