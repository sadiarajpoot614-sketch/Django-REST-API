# 🚀 Django REST API Project

A professional Django REST API project built using **Django** and **Django REST Framework**.  
This project demonstrates API creation, routing, database integration, and a custom homepage using Django templates.

---

## 📌 Features

✅ Django REST Framework API  
✅ Custom Home Page using Django Templates  
✅ API Endpoints  
✅ SQLite Database Integration  
✅ Clean Project Structure  
✅ Admin Panel Support  

---

## 🛠️ Technologies Used

- Python 3.11
- Django 5.2.16
- Django REST Framework
- SQLite Database
- HTML & CSS
